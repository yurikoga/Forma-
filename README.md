# How to Create Responsive Registration Form in HTML & CSS

Um projeto simples de **formulário de cadastro responsivo** usando HTML e CSS.

## ✨ Sobre

Este projeto demonstra como criar um **registration form moderno e responsivo**, ideal para páginas de cadastro.

## 🛠️ Tecnologias

- HTML
- CSS

## 🎯 Funcionalidades

- Formulário de cadastro
- Layout responsivo
- Design simples e limpo

## 🚀 Como usar

1. Baixe ou clone o repositório  
2. Abra o arquivo `index.html` no navegador
